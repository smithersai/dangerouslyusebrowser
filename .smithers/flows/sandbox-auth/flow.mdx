Mint one short-lived, single-use authentication token for a controlled sandbox or BYO agent session using `scripts/mint-sandbox-auth.mjs`.

Rules:
- Never print long-lived master tokens (`DUB_TOKEN`, `SMITHERS_TOKEN`) or pass secrets on child process argv.
- Maintainer and controlled sandbox tokens expire within 120 seconds (max 15 minutes) and redeem atomically once at `POST /auth/exchange`.
- Contributor and viewer tokens are always minted with `trust: "untrusted"` and stripped of `cache:write`, `auth:mint`, `mcp:admin`, `plugin:manage`, and `profile:attach`.
- Report only the token metadata (`tokenId`, `principal`, `role`, `trust`, `scopes`, `expiresAt`) in durable logs and artifacts.
